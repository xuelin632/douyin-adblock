抖音去广告 v1.0.1（Windows x64 便携版）

首次使用
1. 将完整压缩包解压到任意文件夹，不要在压缩包内运行。
2. 双击「安装证书.bat」，按 Windows 提示确认安装本机生成的 mitmproxy 根证书。
   只安装到当前用户；一般不需要管理员权限。此证书用于本地 HTTPS 过滤。
3. 双击「抖音去广告启动器.exe」。无需另外安装 Python 或 mitmproxy。

老用户升级
完全退出抖音，解压新版到新文件夹后使用；原有 mitmproxy 证书可继续使用。
也可以下载 update 补丁包，将 ad_filter.py 覆盖到旧版启动器所在文件夹，重新启动。

本次修复
- 修复修改压缩推荐列表后数据无法解析、后续视频加载失败。
- 直播和媒体响应边接收边转发，避免等待长直播流结束。
- 修复无效 CONNECT 放行，补充没有 SNI 时的直播目标识别。

常见问题
- 找不到抖音：按启动器提示修改同目录 config.txt 中的 douyin=完整路径。
- 启动器运行时将系统代理设为 127.0.0.1:8080；正常退出抖音后关闭系统代理。
  目前不会恢复启动前的全部代理设置，其他系统代理软件可能需要手动重新开启。
- Clash TUN 可以继续开启；避免 Clash 的系统代理功能覆盖本工具的 8080 设置。
- 卸载：退出抖音并删除程序文件夹；不再使用其他 mitmproxy 工具时，
  可在 certmgr.msc 的「受信任的根证书颁发机构」中删除 mitmproxy 证书。
