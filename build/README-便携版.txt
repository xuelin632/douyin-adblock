抖音去广告 v1.1.0（Windows x64 便携版）

首次使用
1. 将完整压缩包解压到任意文件夹，不要在压缩包内运行。
2. 双击「安装证书.bat」，按 Windows 提示确认安装本机生成的 mitmproxy 根证书。
   只安装到当前用户；一般不需要管理员权限。此证书用于本地 HTTPS 过滤。
3. 双击「抖音去广告启动器.exe」。无需另外安装 Python 或 mitmproxy。

老用户升级
完全退出抖音和旧版启动器，下载 update 补丁包，将压缩包中的
「抖音去广告启动器.exe」「ad_filter.py」「DouyinLauncher.cs」覆盖到旧版所在文件夹即可，
无需重新安装运行环境或证书。

v1.1.0 升级亮点
- TLS 白名单精准解密：仅解密 www.douyin.com，其他所有网站、软件、直播和视频流直接透传。
- 自动保存和恢复启动前的系统代理；若原本开着系统代理（如 Clash 7897），自动串联不断线。
- 无论退出抖音还是直接关闭黑框窗口，都会自动恢复系统代理并清理后台代理进程。
- 默认端口改为 18080（冲突自动顺延至 18099），并自动检测代理就绪后再切换代理。
- 防止双开启动器，日志增加完整日期并支持 1 MB 自动轮转。

常见问题
- 找不到抖音：按启动器提示修改同目录 config.txt 中的 douyin=完整路径。
- Clash TUN 模式可直接并行开启，规则模式下抖音走 DIRECT 直连，不消耗节点流量。
- 卸载：退出抖音并删除程序文件夹；不再使用其他 mitmproxy 工具时，
  可在 certmgr.msc 的「受信任的根证书颁发机构」中删除 mitmproxy 证书。
